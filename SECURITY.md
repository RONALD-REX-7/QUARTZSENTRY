## Reporting a Vulnerability

If you discover a security vulnerability within **QUARTZSENTRY**, please report it responsibly:

1. **Do not create a public issue**: Please do not open public GitHub issues or discussions for sensitive security bugs.
2. **Contact Privately**: Send details via GitHub Security Advisory (preferred) or email the maintainer directly at `ronaldrex.ch@gmail.com`.
3. **Include Details**: Provide a description of the vulnerability, reproduction steps or proof-of-concept, and expected vs observed impact.

We take security seriously and will acknowledge receipt within 48 hours and work on remediation promptly.
